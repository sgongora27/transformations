# World-State Transformations

This repository contains the source code for the experiments reported in [World-State Transformations for Neuro-symbolic Interactive Storytelling](https://arxiv.org/abs/2605.24719).

Please check the [PAYADOR](https://github.com/pln-fing-udelar/payador) repository for an up-to-date version of the system.
